# 매장 갤러리 사진

`index.html`의 **지점 순서**와 파일 번호가 같습니다.

| 파일 | 지점 |
|------|------|
| `01.jpg` | 강남역점 |
| `02.jpg` | 홍대입구점 |
| `03.jpg` | 신촌점 |
| … | … |
| `30.jpg` | 제주점 |

## 넣는 방법

1. 매장 사진을 JPG 또는 WebP로 준비 (가로 800~1200px 권장)
2. 위 표에 맞게 `01.jpg`, `02.jpg` … 로 이 폴더에 저장
3. 브라우저에서 페이지 새로고침

파일이 없으면 `default.svg`(사진 준비 중)가 표시됩니다.

## 한 지점만 바꿀 때

해당 번호 파일만 교체하면 됩니다. HTML 수정은 필요 없습니다.
