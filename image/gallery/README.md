## 사진 추가할 때

1. `09 포카드 … .jpg` 형식으로 이 폴더에 저장
2. `index.html`의 `GALLERY_ITEMS` 배열에 해당 항목의 `image` 경로와 `name` 추가 (또는 플레이스홀더 항목을 실제 항목으로 교체)
3. 페이지 새로고침
